SageIris employs a distributed, event-driven architecture to process and serving as a predictive analytics orchestrator and high-performance processor.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/SageIris.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

SageIris is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
